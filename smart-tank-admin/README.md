# Smart Tank Admin Dashboard

This is the admin dashboard for the Smart Tank project, built with React, TypeScript, Vite, and Material-UI.

## Project Setup

1.  **Clone the repository:**
    ```bash
    git clone <your-repo-url>
    cd smart-tank-admin
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Set up environment variables:**
    Create a `.env` file in the root of the project and add your backend API URL:
    ```
    VITE_API_BASE_URL=http://localhost:8080/api
    ```

## Available Scripts

### `npm run dev`
Runs the app in development mode. Open http://localhost:5173 to view it in the browser.

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run lint`
Runs the linter to check for code quality issues.
